## 1. New Files Created

### 8 Draw AOD/
- `calculate_freq.m` - Calculate aerosol subtype frequency
  - Inputs: VFM, ALay_05km, surface_mask, freq_block, cnt_block, lon_edges, lat_edges
  - Aerosol classification:
    - Total: types 1-7
    - Anthropogenic: 3 (Polluted Cont/Smoke), 5 (Polluted Dust), 6 (Elevated Smoke)
    - Natural: 1 (Clean Marine), 2 (Dust), 4 (Clean Continental), 5 (Polluted Dust), 7 (Dusty Marine)
  - Note: Polluted Dust(5) belongs to both Anthropogenic and Natural

- `plot_freq_block.m` - Plot aerosol frequency distribution
  - Calls the unified plot_grid_block function

- `create_empty_freq_grid.m` - Initialize frequency grid
  - Creates 3D freq_block (nlat x nlon x 3) for [Total, Anthropogenic, Natural]
  - Creates cnt_block for total valid profile count

- `plot_grid_block.m` - Unified grid data plotting function
  - Masks areas outside China to NaN
  - Plots China boundary shapefile
  - Shared by plot_aod_block and plot_freq_block

## 5. Frequency Calculation Logic

- Denominator: valid profiles (surface_mask == 1)
- Only profiles with surface_mask == 1 are counted in both numerator and denominator
