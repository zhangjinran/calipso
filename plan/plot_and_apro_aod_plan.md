# 绘图与 APRO AOD 修复计划

## 目标
修复季节趋势图显示问题，并定位 APRO 分类 AOD 图中的高亮斑点。

## 执行顺序

1. 用 `final_blocks.mat` 读取异常网格和值分布，确定异常位置和时间范围。
2. 先用人工构造数据验证季度分组、年度均值、缺失年份、网格方向和色标。
3. 对异常网格回查 APro Extinction、Total/Perpendicular Backscatter、VFM 类型和 surface mask。
4. 检查无效值、填充值、单位、比例因子、`dz` 和 type-5 退偏振拆分。
5. 在同一文件和同一网格上比较 ALay AOD 与 VFM+APro AOD。
6. 修复后建立固定异常点回归测试。

## 证据要求

每次修复保留：异常网格坐标、原始字段摘要、修复前后 AOD、对应 block 和图像。

## 验收标准

- 季节图在人工数据和真实数据上方向、色标、季度含义一致。
- 高亮斑点可解释、消除或被明确判定为真实信号。
- ALay 与 VFM+APro 的差异有定量说明。
