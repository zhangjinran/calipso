# 主函数提速计划

## 目标
在结果一致的前提下，降低 HDF 读取和重复计算开销。

## 已知基线

- 17 个文件主处理约 91.87 秒。
- HDF 数据读取约占 75%。
- 全局 block 和 interval block 当前重复调用计算函数。

## 执行步骤

1. 保留当前基线日志和 `final_blocks.mat`。
2. 给 interval 计算增加独立计时。
3. 继续 hdf2mat 的日级 MAT 方案，先使用兼容性较好的逐文件接口。
4. 用 MAT 缓存替换主函数中的重复 HDF 读取。
5. 合并或复用全局与 interval 的中间计算结果。
6. 每次优化比较耗时、失败文件、block 尺寸和数值差异。

## 验收标准

- 结果与基线在容差范围内一致。
- 记录总耗时和各阶段耗时。
- MAT 缓存模式可回退到原始 HDF 模式。
